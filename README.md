# Personal Portfolio Website

Welcome to the repository for my personal portfolio! This is a user-friendly, responsive website built to showcase my projects, technical skills, and professional experience.

## 🌐 Live Demo
Check out the live deployed version of the site here: **[afkarfaizal.github.io/portfolio-website](https://afkarfaizal.github.io/portfolio-website/)**

## ✨ Features
* **Interactive Skills Grid:** A clean layout detailing my technical proficiencies.
* **Contact Form:** An easy way for visitors or potential collaborators to get in touch.
* **CV Integration:** Direct access for users to view and download my professional CV.
* **Responsive Design:** Optimized for seamless viewing across both desktop and mobile devices.

## 🛠️ Technologies Used
This project is built using core web technologies:
* **HTML5** (`index.html`)
* **CSS3** (`style.css`)
* **JavaScript** (`js.js`)

## 📂 Repository Structure
* `/CV` - Contains my downloadable professional resume/CV files.
* `/images` - Image assets, profile pictures, and icons used across the site.
* `index.html` - The main structure and content of the webpage.
* `style.css` - Custom styling, UI design, and responsive layout rules.
* `js.js` - Interactive functionality and dynamic webpage elements.
